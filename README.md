# Notes-page--Js-
Pagina de notas con Javascript (vanilla)

Maquetado de una pagina web simple utilizando JS. >
Se busca mantener los datos de las notas/ediciones sin perderlos al refrescar la página.
Ademas de implementar funciones básicas como editar o eliminar, se añadió una opción de "color picker" para cambiar el color predeterminado de las mismas (o regresar a este). Con el plus de un ""detector de luminosidad"" que resalta el contenido de las notas a un color mas oscuro cuando el color elegido es demasiado brillante para el texto default. 

---------------------------------------------------------------------------

Modeling of a simple website using JS. ENG>
It seeks to keep the data of the notes/edits without losing them when refreshing the page.
In addition to implementing basic functions such as editing or deleting, a "picker color" option was added to change the default color of the same (or return to it). With the plus of a ""luminosity detector"" that highlights the content of the notes to a darker color when the chosen color is too bright for the default text.
